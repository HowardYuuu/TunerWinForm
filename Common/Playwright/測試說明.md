# Playwright 測試說明

## 概述

此資料夾包含專案的 Playwright 自動化測試相關資源。

```
Common/Playwright/
├── images/              # 測試截圖存放位置
│   ├── README.md       # 截圖說明文件
│   └── .gitkeep        # Git 追蹤標記
└── 測試說明.md         # 本文件
```

## 測試截圖保存指引

### 方法 1：使用程式碼配置

在測試程式碼中，配置截圖保存路徑：

```csharp
// C# 範例
var screenshotPath = Path.Combine(
    Directory.GetCurrentDirectory(), 
    "..", "..", "..", "..", 
    "Common", "Playwright", "images", 
    "screenshot.png"
);
await page.ScreenshotAsync(new() { Path = screenshotPath });
```

### 方法 2：使用環境變數

設定環境變數來指定截圖輸出路徑：

```bash
export PLAYWRIGHT_SCREENSHOT_DIR="./Common/Playwright/images"
```

### 方法 3：使用 Playwright 配置檔

在 `playwright.config.ts` 或測試設定中：

```typescript
use: {
  screenshot: 'only-on-failure',
  screenshotPath: './Common/Playwright/images'
}
```

## ChatRoom 專案測試

ChatRoom 即時聊天室專案的測試包括：

1. **登入測試**
   - 驗證用戶可以輸入暱稱並加入聊天室
   - 檢查暱稱唯一性驗證

2. **訊息功能測試**
   - 發送文字訊息
   - 訊息右側顯示（自己的訊息）
   - 訊息左側顯示（他人的訊息）

3. **Emoji 測試**
   - 打開 Emoji 選擇器
   - 選擇並發送 Emoji
   - 驗證 Emoji 正確顯示

4. **圖片功能測試**
   - 上傳圖片
   - 圖片預覽
   - 發送圖片訊息
   - 貼上圖片（Ctrl+V）

5. **多用戶測試**
   - 多個用戶同時在線
   - 用戶加入/離開通知
   - 在線人數統計

6. **已讀狀態測試**
   - 訊息發送狀態
   - 已讀計數更新

7. **系統訊息測試**
   - 連線事件置中顯示
   - 系統通知訊息

## 截圖命名規範

建議使用以下命名格式：

```
{專案名稱}-{功能}-{描述}.png
```

範例：
- `chatroom-login-page.png`
- `chatroom-emoji-picker.png`
- `chatroom-multi-users-chat.png`

## 注意事項

1. **截圖品質**：使用 PNG 格式以保持清晰度
2. **檔案大小**：注意控制截圖檔案大小
3. **敏感資訊**：不要在截圖中包含真實的敏感資訊
4. **定期清理**：定期清理不再需要的舊截圖
5. **文件更新**：新增測試時更新 `images/README.md`

## 測試執行範例

```bash
# 進入 ChatRoom 專案目錄
cd ChatRoom

# 執行應用程式
dotnet run

# 在另一個終端執行測試（如果有獨立的測試專案）
dotnet test

# 或使用 Playwright CLI
playwright test --headed
```
